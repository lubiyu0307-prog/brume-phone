# 霧語 Brume Phone

SillyTavern 擴充：一支霧面玻璃風的小手機。通用，不綁任何角色。by Lubí。

目前 v0.25.13。在 iPhone 的 Safari 上調的；Android 與電腦瀏覽器能用，排版沒有一台一台對過，看到怪的請附設定裡的除錯紀錄回報。

## 有什麼

- **LINE**：跟他傳訊息、傳照片（接 Google 或 OpenAI 時照片直接送去看）、貼圖、通話；他會寄包裹、叫外送；劇情接手機、手機接劇情
- **IG、脆**：他跟配角們的帳號、限動、留言，路人會出現；現實模式寫的是現在的台灣
- **圖庫**：證件照、快照（從正文抓畫面生圖）、兩人合照；生圖用 Gemini 或 OpenAI 自己選，金鑰在右上角生圖設定貼
- **音樂、小遊戲、電話、行事曆**（劇情／現實兩本）、**冰箱門**（同居解鎖）、**尋找**（交往解鎖，看他現在在哪）、**偷看他的手機**
- **鎖定畫面**：天氣（現實時間是真的天氣，設定裡填妳的城市；劇情時間是故事裡的）、通知
- **關係階段**：陌生→曖昧→交往→同居，解鎖不同的 App；他會照階段主動傳
- **推播**：酒館關著也收得到他的 LINE（見 PUSH.md）；可以把霧語加到手機桌面，打開就是手機不是酒館
- **記憶書**：整理你們聊過的事，跟酒館世界書雙向同步
- **省 token 模式**：只送卡、用到的世界書和最後幾則正文

手機和電腦同步，資料存在酒館伺服器的使用者檔案裡。

## 安裝

酒館 → 擴充功能 → 安裝擴充功能 → 貼上這個 repo 的網址 → 重新整理。
右下角會出現一個小手機按鈕（可以拖著換位置）。古風、奇幻這類沒有手機的故事，設定裡「這張卡不用小手機」關掉就好。

## 回報問題

設定 → 最下面「複製除錯紀錄」，貼給作者。紀錄裡只有畫面尺寸與版本，沒有聊天內容。
