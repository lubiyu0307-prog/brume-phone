# 霧語 Brume Phone

SillyTavern 擴充：一支霧面玻璃風的小手機。通用，不綁任何角色。

目前 v0.21：手機和電腦同步（存在酒館伺服器的使用者檔案）；LINE、IG、脆、相本＋快照、音樂、小遊戲、電話、行事曆（劇情／現實兩本）、冰箱門（同居解鎖）、尋找（交往解鎖，看他現在在哪）、鎖定畫面天氣（現實時間是真的天氣、劇情時間是故事裡的）、包裹（他叫的外送、寄的東西）、偷看他的手機；關係階段、他主動傳、劇情接手機、鎖定畫面通知、酒館關著也收得到的推播（見 PUSH.md）、放到手機桌面；記憶可以寫進酒館世界書。

## 安裝

酒館 → 擴充功能 → 安裝擴充功能 → 貼上這個 repo 的網址 → 重新整理。
右下角會出現一個小手機按鈕（可以拖著換位置）。
